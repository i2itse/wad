Project Overview
Objects Required
1. Property

Stores house/flat details.

2. Tenant

Stores renter details.

Relationship:

One Property → Many Tenants
STEP 1 — Open Salesforce Setup

From your current Salesforce page:

Click ⚙️ Gear Icon
Click Setup
STEP 2 — Create Property Object

Search:
Object Manager

Then:

Click Object Manager
Click Create
Select Custom Object

Fill details:

Field	Value
Label	Property
Plural Label	Properties
Record Name	Property Name
Data Type	Text

Enable:

Allow Reports
Allow Activities

Click Save

STEP 3 — Create Fields for Property

Open:
Fields & Relationships → New

Create these fields one by one.

A) Property ID
Option	Value
Data Type	Auto Number
Field Label	Property ID
Display Format	PRO-{0000}

Save.

B) Property Type
Option	Value
Data Type	Picklist
Label	Property Type

Values:

Flat
House
Apartment
Villa
Shop

Save.

C) Address
Option	Value
Data Type	Text Area
Label	Address

Save.

D) Rent Amount
Option	Value
Data Type	Currency
Label	Rent Amount

Save.

E) Status
Option	Value
Data Type	Picklist
Label	Status

Values:

Available
Rented

Save.

STEP 4 — Create Tenant Object

Again:

Object Manager → Create → Custom Object

Fill:

Field	Value
Label	Tenant
Plural Label	Tenants
Record Name	Tenant Name
Data Type	Text

Save.

STEP 5 — Create Fields for Tenant
A) Tenant ID
Option	Value
Type	Auto Number
Label	Tenant ID
Format	TEN-{0000}

Save.

B) Phone Number
Option	Value
Type	Phone
Label	Phone Number

Save.

C) Email
Option	Value
Type	Email
Label	Email

Save.

D) Move In Date
Option	Value
Type	Date
Label	Move In Date

Save.

STEP 6 — Create Relationship

Now create:
Tenant → Property relationship

Inside Tenant object:

Fields & Relationships → New

Select:

Lookup Relationship

Related To:

Property

Next → Next → Save

This creates:

One Property
Many Tenants

Exactly as required in your project.

STEP 7 — Create Tabs

Search:
Tabs

Create:

Property Tab
Tenant Tab

Choose icons and save.

STEP 8 — Create Salesforce App

Search:
App Manager

Then:

App Name:

Rental Property Management

Tenant Tab
Reports
Dashboards

Finish.
